# Requirements Traceability Matrix (RTM)

The Requirements Traceability Matrix is used to connect requirements to related test cases,
results, and clear linkages to other project artefacts (Bose, 2026). This allows improved
visibility of testing across the software development lifecycle and dependencies between
business needs (Bose, 2026).
