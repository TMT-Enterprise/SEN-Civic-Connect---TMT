# CR-002: Changing from sms simulation to email simulation/CHange in communication channel

| Field | Detail |
|---|---|
| Requested by | Mutshidzi Nduvheni |
| Date | 08/09/26 |
| Requested change | Instead of using SMS to simulate our notification system for civicConnect, we will be using emails instead. |
| Reason / expected value | Notifications sent to users and staff will be more detailed than the SMS notification system and is also best for richer, traceable communication. Implementing an email simulation allows effective testing on formatting, links and detailed content. |
| Requirements affected | FR-006 |
| Architecture/design affected | The notification component/interface must support email rather than an SMS service. The overall architecture (TBD) will remain unchanged |
| UI/API/data affected | UI and API: The notification functionality and relevant API/service logic must be updated to generate and send email notifications. Data affected: Users may need to provide their emails rather than their mobile number for notifications.
| Security/privacy impact | Appropriate access control and protection of user contact information must be maintained |
| Quality/testing impact | Email test must verify that the correct email is generated and associated with the correct request and recipient and the request events trigger the expected email notification|
| Scope impact | Notification channel changes from SMS to email |
| Schedule/resource impact | Development and testing effort is required to replace the SMS notification approach with email functionality. Impacted is expected to be minimal |
| Cost impact | n/a |
| Risk impact | The change from SMS to email may include impact risks such as email-address validity and potential delivery failures |
| Recommendation | ACCEPT / MODIFY / DEFER / REJECT |
| Approved by | (two reviewers, names) |
| Rationale | The change maintains the initial requirement of notifying users while changing the delivery mechanism to email. The change does not affect the overall purpose of CivicConnect |
